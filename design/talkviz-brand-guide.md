# TalkViz — mini brand guide

**Tagline:** Talk to your data. **Theme:** black/charcoal with blue accents.

**Product description:** A voice-first analytics assistant that turns natural-language questions into read-only database queries, interactive visualizations, and spoken summaries.

## Logo assets

- `talkviz-logo.svg`: optional light-background horizontal wordmark.
- `talkviz-logo-dark.svg`: **primary** transparent horizontal wordmark for dark backgrounds.
- `talkviz-logo-on-dark.svg`: primary wordmark with a solid charcoal background.
- `talkviz-icon.svg`: square app/avatar icon.
- `talkviz-logo.png`: PNG of the light-background variant.
- `talkviz-logo-dark.png`: transparent PNG of the primary dark-theme variant.
- `talkviz-icon.png`: PNG app icon.

## Colors

| Role | Hex |
| --- | --- |
| Background (near-black) | `#09090B` |
| Surface (charcoal) | `#18181B` |
| Elevated / borders | `#27272A` |

| Main text (silver-gray) | `#D4D4D8` |
| Muted text | `#A1A1AA` |

## Typography

Use **Inter** for web UI and branding, with a system sans-serif fallback. For code or SQL blocks, use **JetBrains Mono** or another readable monospace font.

## Voice and personality

Clear, curious, and conversational. Speak in compact summaries and let the chart show the full detail. Favor informative labels over hype.
